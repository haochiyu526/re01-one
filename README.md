## 岗位管理
-任务类型：思维导图
-思维导图：
![功能思维导图](images/岗位管理_功能思维导图.png)
-说明文字：
1.岗位查询：支持关键字检索、分页查询岗位列表
2.岗位新增：录入岗位信息，校验岗位编码唯一性
3.岗位编辑：修改岗位基础信息
4.岗位删除：删除操作增加二次确认
5.状态管理：对岗位执行启用/禁用操作
